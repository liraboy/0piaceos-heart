# Pedro Lira AKA 0piaceos

Just a small Python experiment using my name from online games.

An animated light pink heart made of the word "0piaceos", on a black background.

![preview](preview.gif)

## Run it

```bash
pip install -r requirements.txt
python main.py
```

Missing packages are installed automatically when you run `main.py`.

## Customize

Edit the settings at the top of `main.py`:

- `NAME`: the text that forms the heart
- `BACKGROUND` and `COLORS`: colors
- `SPACING_X` and `SPACING_Y`: how many words fit in the heart
- `SAVE_GIF`: also saves `preview.gif`

## Built with

Python, Matplotlib and NumPy.
